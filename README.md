# Планер личного развития — Настя Маринина

Сайт-планер на 6 месяцев (сентябрь 2026 — февраль 2027).

## Как задеплоить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `planner`)
2. Загрузи все файлы этой папки в корень репозитория
3. Перейди в Settings → Pages → Source → **GitHub Actions**
4. Запушь изменения в ветку `main` — сайт появится по адресу  
   `https://ТВО_ИМЯ.github.io/planner/`

## Файлы

```
index.html   — разметка
style.css    — тёмная тема, лавандовые акценты
data.js      — план на 26 недель (задачи, даты, фазы)
app.js       — логика планера (статусы, перенос, прогресс)
.github/workflows/deploy.yml — автодеплой на GitHub Pages
```

## Функциональность

- Недели пн–вс с навигацией (стрелки или кнопки)
- Задачи из плана (лекции, ментор, задания) на нужных днях
- ✓ Выполнено / ✗ Не выполнено — одним кликом
- ↷ Перенести — выбрать другой день для любой задачи
- ＋ Добавить свою задачу на любой день
- Прогресс-бар в шапке — % выполненных задач от общего плана
- Данные сохраняются в localStorage (не нужен сервер)
